Sistema operativo:
Es el software que administra el funcionamiento del computador y permite ejecutar programas como Node.js. También controla los recursos del sistema.

Node.js:
Es un entorno de ejecución que permite utilizar JavaScript en el servidor para crear aplicaciones web y APIs.

Aplicación server.js:
Es el archivo donde se escribe el código del servidor y se definen las rutas que responderán a las solicitudes de los usuarios.

Puerto:
Es el número por el cual el servidor recibe las solicitudes. En esta práctica se utiliza el puerto 3000.

Logs:
Son registros que muestran la actividad del servidor, ayudan a identificar errores y permiten monitorear su funcionamiento.
